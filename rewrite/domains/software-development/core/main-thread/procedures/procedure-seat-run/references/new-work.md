# New work on a seat

New work on a seat, once the caller has settled with the human where it starts and which agent takes it, and moved the seat when it starts elsewhere. Its terms are SKILL.md's; Changes' steps are the ones SKILL.md's New work sends you to read with this file.

Follow the step for the agent the caller names, and tick it in the todo list.

1. **The hot agent:** a tester with no plan seq handed in: Changes' worktree check (its step 2) first, before any status change; its `stopped: plan gate needed` hand-back ends this work. Then run `sh "<seat scripts>/seats/seats.sh" task --effort '<effort folder>' --seat '<seat>'`. Exit 0: go on; an exit 5 naming the seat's pair: Changes' The pair hold (its step 2); any other non-zero exit: send nothing (SKILL.md Always, Send nowhere). Then Changes' Send, its new-work form, whose `REPORT:` line carries a hot tester's `PLAN:` path for a new plan and its `REPORT:` path for TEST; its agent unreachable: Changes' Unreachable (its step 5), with the re-seat note (SKILL.md Interface); its result: SKILL.md Results, then hand the seat back to the caller for this work alone.
2. **A fresh agent:** run `sh "<seat scripts>/seats/seats.sh" handover --effort '<effort folder>' --seat '<seat>'`; a non-zero exit: send nothing (SKILL.md Always, Send nowhere). Then hand the work back to the caller's plan step as a new plan on that seat, shown at the dispatch-plan gate with its plugins; its dispatch comes back to SKILL.md Launch, then Results.
