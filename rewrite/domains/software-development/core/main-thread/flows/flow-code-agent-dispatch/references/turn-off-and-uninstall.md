# Turning off and uninstalling

What the human removes to turn the inject hook off or to uninstall this flow. Step numbers are SKILL.md's.

- **To turn the inject hook off,** the human removes the `PreToolUse` › `Agent` entry running `prepare-agent-prompt.sh` from `settings.json`, then runs `/hooks` or restarts. Step 1 then exits 1, so no dispatch goes out until the entry is back. Step 1's Fix item prints the exact entry.
- **To uninstall,** the human removes these from `settings.json`, then runs `/hooks` or restarts: the inject hook entry; the seat bind entry (`PostToolUse` › `Agent`, running `seat-bind-hook.sh`); the report commit entry (`SubagentStop`, running `report-commit-hook.sh`); the block relay entry (`SubagentStop`, async, running `block-relay-hook.sh`); the three approval gate entries (the Stop entry running `gate-stop-hook.sh`, the `PreToolUse` › `AskUserQuestion` entry running `gate-question-hook.sh` and the `PostToolUse` › `AskUserQuestion` entry running `gate-answer-hook.sh`); the events guard entry (`PreToolUse` › `Bash`, running `events-guard-hook.sh`); the Crucible-space entry in `permissions.additionalDirectories`; the space's `Edit(//<space>/**)` rule in `permissions.allow`; and its `Edit(//<space>/efforts/*/events/**)` rule in `permissions.deny`. Step 1 then fails until they are back.
