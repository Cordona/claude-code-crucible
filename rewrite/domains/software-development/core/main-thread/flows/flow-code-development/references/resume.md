# Resume: the effort's seats after a break

Its terms and steps are SKILL.md's.

1. **The context:** load `procedure-context` with the Skill tool, with the effort folder, and take the `CONTEXT_DOCS:` or `CONTEXT_FILE:` line it hands back; nothing below runs until it hands one over. Once it does, come back here; never split again a part that has a seat in the seat list, chosen or later (SKILL.md 2.4); a dropped seat no longer counts.
2. **The seats,** read only through the scripts: never run `events.sh` or read `events/`, but for an event file a script hands over by path (the done test's `LAST_REPORT:`). Run `list=$(sh "<scripts>/seats/seats.sh" list --effort '<effort folder>') && printf '%s\n' "$list" | jq -r '.seats[] | [.seat, .status, .worktree] | @tsv'`. No seats: none is held (none was chosen, or every one was dropped): go on from SKILL.md step 2. A seat's part is its task, from this session's todo item (`<seat>: …`) or the conversation (no script reads a dispatch's task); when neither holds it, step 3 says what to do. Never run `git` in a worktree or the checkout to learn a part; ask the human instead. When a read fails, show its output and record `not checked` for each seat it leaves unknown.
3. **One state per seat,** by its status:
   - **`chosen`:** a plan never answered. When this session still holds its part (its todo item `<seat>: <task>` or the conversation, as after a compaction), take that part through SKILL.md step 2.5 with that seat; when it can't tell: show `Not done: <seat>: plan never answered.` (SKILL.md step 5's form), and offer to drop it; on a yes, `sh "<scripts>/seats/seats.sh" drop --effort '<effort folder>' --seat '<seat>'`; a refusal: show its stderr and leave the seat. The human asks for the work again if they still want it.
   - **`open`:** never launched (a denial, or a break before the call): take its part through SKILL.md step 2.5 again when step 2 found its task; otherwise show `Not done: <seat>: task unknown.` (SKILL.md step 5's form) and ask the human for its task; on an answer, take it through SKILL.md step 2.5 with that seat; otherwise leave it.
   - **`working`:** its todo item records `not committed`, or no send since its last result: SKILL.md step 4's `working` line. Otherwise, after a compaction in the same session, its run may still end: wait for it (SKILL.md step 4). In a new session, or when you can't tell, ask the human whether its agent may still run: "it may" records it `not checked`; "it doesn't": SKILL.md step 4's `working` line, its run ended.
   - **`idle`:** show the line `Checked earlier, <done or blocked>: <task> · <short sha of its worktree's HEAD>`, done or blocked by SKILL.md Terms' done test, `<task>` the seat's name when step 2 found none; its card only when the human asks.
   - **`gave-up`:** SKILL.md step 4's `gave-up` line.
4. **Parts with no seat:** a part the conversation still shows `waiting for <task>` goes on once that part is done (SKILL.md 2.4); in a new session the human may name such parts (SKILL.md Terms, a part's record).
5. **Then** go on from SKILL.md step 5.
