## Other facts the probes surfaced

- **SubagentStop fires mid-work when an agent parks on a background shell.** In this config a plain `sleep N` is not allowed in the foreground, so the agent ran it in the background and ended its turn "waiting": SubagentStop fired then (with that waiting message), and again when the shell finished and the agent really ended. The kit now uses `perl -e 'sleep N'`. Evidence: `logs/P2c-run1-shells-backgrounded/`, `logs/P2b-run1-shell-backgrounded/` (in the latter, TaskStop after that early stop fired nothing more).
- **Interactive sessions run Claude Code's own helper agents, and their SubagentStop fires with `agent_type: ""`** and no SubagentStart (seen in P2c and P2x, none headless). A hook must not treat an empty type as a job.
- **In the interactive session the Agent tool had no `run_in_background` parameter**: every agent ran in the background, so the foreground case is headless only here (P5, P8).
- SubagentStop stdin carries `agent_id`, `agent_type`, `agent_transcript_path`, `last_assistant_message`, `stop_hook_active`, `background_tasks`, `session_id`.
- Debug logs record each agent's end: `agent_completion agentId=... exitPath=completed|cancelled|error`. It is the one trace for the cases where no hook fires (turn limit shows `completed`).

- **Fixture commits and the owner's signing setup.** The repo fixtures (P16 to P18, and P19's first runs) were committed with the owner's global git config. That config has `commit.gpgsign=true`, so each fixture commit in `/Users/Shared/crucible-sandbox/stop-hook-probe/P16*`–`P18/repo` carries a signature from the owner's key, through the running gpg agent. They are local sandbox commits, never pushed. The kit now makes fixtures with `fgit`: no global or system git config, `commit.gpgsign=false`, and a fixture identity. Rerun fixtures are unsigned.

## Could not probe

- A transient API failure (5xx, overload, rate limit, network drop): no safe way to cause one. Only the 404 model error was probed (P2e).
- An agent that runs out of context: not attempted.
- The default hook timeout's exact value: only shown to be above 120 s.
