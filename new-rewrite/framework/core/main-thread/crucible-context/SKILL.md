# Context

The context is the outside material the work needs: references to files, folders and links, and short notes written for the work. An agent knows nothing of this conversation, so what it needs from it has to be written down; what it can find in the work itself doesn't.

Reference what already exists rather than copying it: a copy goes stale and costs every agent its tokens. Give each reference a one-line why that says what the agents need it for, such as "the retention rule the prune must follow", never just "docs". Write a note only for what was worked out here and lives nowhere else, and never put a secret in one: a note is sealed and read by every agent sent after it. Add an entry only after you have read it yourself; a search hit is not yet an entry.

When the context looks complete, ask the human whether it is done, at the recorded gate the cut script's `--help` names, with the draft's path on the card. On their yes, cut it. A cut version never changes: what you add or take out later goes into the next version, after another such gate.

Take an entry out only with the human's reason.

The scripts you run are in this skill's `scripts/main/` folder; each one's `--help` is its contract.
